# KPI Definitions

## Daily Active Users (DAU)
Count of distinct users who generated any event in the last 24 hours.

## Revenue
Sum of payment amounts recorded in the last 30 days.

## Churn Events
Count of churn events recorded in the last 24 hours.

## Anomalies
An anomaly is a statistically significant deviation from expected behavior based on seasonal trends and isolation-based outlier scoring. Each anomaly includes:
- Score: isolation score normalized to highlight severity.
- Root cause: top contributing segment by country, plan, and event type.
